# EnviConnect

EnviConnect is a browser-only community board for local sustainability projects. Discover an initiative, pledge your time, or start one of your own.

## What it does

- Filters projects by clean-up, growing, and education.
- Lets visitors join or leave projects and see impact totals update immediately.
- Adds projects through a validated modal form; creators are automatically joined.
- Stores projects and joined-project IDs in `localStorage` under `enviconnect-v1`.
- Seeds six example projects on a first visit. No accounts, database, or backend are used.

## Run locally

```bash
npm install
npm run dev
```

## Stack

React 19, TanStack Start/Router, Tailwind CSS v4, TypeScript, and Lucide icons.
