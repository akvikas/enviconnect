# EnviConnect

EnviConnect is a responsive, front-end community hub for discovering and organizing local sustainability initiatives.

## Features

- Browse and filter sustainability projects by cause
- Join a local project; participation is persisted in browser storage
- Create a new project through an accessible modal form
- Live community-impact counters
- Responsive layout for mobile and desktop

## Run locally

Open `index.html` in any modern browser. No build step or dependencies are required.

## Technology

HTML, CSS, and vanilla JavaScript. Project data uses `localStorage` so the interface remains usable without a backend.
